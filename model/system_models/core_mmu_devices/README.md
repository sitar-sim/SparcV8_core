# system_models/core_mmu_devices/

Planned configuration: the SPARC V8 core, an MMU, main memory, and the
peripherals (timer, interrupt controller, serial device), connected over
a ports-and-nets bus below the MMU (see
`../../../Plan_SoC_Integration_Roadmap.md`'s "Phased development order",
stages 2 and 3). This is one of the three target testbench tiers. Not
yet implemented -- see `../../../Plan_MMU_integration.md` and
`../../../Plan_Devices_integration.md` for the plan.
