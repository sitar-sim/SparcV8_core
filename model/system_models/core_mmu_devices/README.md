# system_models/core_mmu_devices/

Planned configuration: the SPARC V8 core, an
[MMU](https://sitar-sim.github.io/SparcV8_core/model_components.html#mmu),
main memory, and the
[peripherals](https://sitar-sim.github.io/SparcV8_core/peripheral_devices.html)
(timer, interrupt controller, serial device), connected over a
ports-and-nets bus below the MMU. This is one of the three target
testbench tiers. Not yet implemented.
