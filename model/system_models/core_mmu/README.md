# system_models/core_mmu/

memory, still without devices or caches, using the same procedure-handshake
connection style `core_only/` uses today (see
`../../../Plan_SoC_Integration_Roadmap.md`'s "Phased development order",
stage 1). Not yet implemented -- see
`../../../Plan_MMU_integration.md` for the plan.
