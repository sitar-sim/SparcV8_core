# sitar_pygments_lexer/

Vendored copy of the Sitar language's Pygments lexer, from the
[sitar repository](https://github.com/sitar-sim/sitar/tree/master/sitar_pygments_lexer),
so this repo's `docs/requirements.txt` is self-contained and doesn't need a
sibling checkout of sitar. Provides syntax highlighting for Sitar code
blocks in this repo's own MkDocs documentation. See `docs/README.md` for
how it's installed.
